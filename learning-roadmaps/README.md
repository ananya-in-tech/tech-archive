# Learning Roadmaps

Curated sequences that help learners move from prerequisites to practical competence in a subject or role.

## Suggested roadmaps

- Software engineering foundations
- SDE internship and new-graduate preparation
- Frontend development
- Backend development
- Full-stack development
- Mobile application development
- AI and machine learning
- Data science and data engineering
- Cybersecurity
- Cloud and DevOps
- System design

A roadmap should define its intended audience, prerequisites, learning outcomes, ordered milestones, estimated effort where defensible, and links to resources in the relevant subject directories. Keep roadmaps focused on skill development rather than promising a specific hiring outcome.
