# Data Structures and Algorithms

A focused home for data structures, algorithm design, complexity analysis, problem-solving patterns, and coding practice.

## Existing learning material

The previous DSA collection is being retained and organized under this directory. Its detailed [DSA roadmap](ROADMAP.md), topic modules, and existing PDF reference are preserved as part of this migration.

## Topic groups

- Foundations and complexity analysis
- Mathematics for DSA
- Arrays, strings, hashing, and searching
- Sorting, two pointers, and sliding window
- Linked lists, stacks, and queues
- Recursion and backtracking
- Trees, heaps, and tries
- Graph algorithms
- Greedy algorithms and dynamic programming
- Number theory and advanced data structures
- Interview patterns and practice sheets

Continue using the topic modules for comprehensive concept explanations and problem-solving practice. Add curated courses, books, research, and references where useful. Keep supporting diagrams and attachments close to their relevant topic.
