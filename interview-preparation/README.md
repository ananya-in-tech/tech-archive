# Interview Preparation

A dedicated collection for preparing for software engineering internships and full-time technical roles.

## Preparation areas

- **Coding interviews:** DSA patterns, problem-solving practice, complexity analysis, and timed assessments.
- **Core CS interviews:** operating systems, computer networks, databases, OOP, and programming-language fundamentals.
- **System design interviews:** low-level design, high-level design, and architecture discussions.
- **Machine-coding rounds:** implement a working, maintainable solution under practical constraints.
- **Behavioral interviews:** communication, collaboration, ownership, and reflective examples.
- **Interview experiences:** first-hand accounts with dates and context, clearly marked as personal experiences.
