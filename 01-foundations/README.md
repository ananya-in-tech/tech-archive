# Foundations

Build the mathematical and analytical foundations that make later computer-science topics easier to understand.

## Subjects

- **Mathematics for computing:** algebra, functions, logarithms, and mathematical reasoning.
- **Discrete mathematics:** logic, sets, relations, functions, proofs, combinatorics, and graph theory.
- **Probability and statistics:** probability, distributions, descriptive statistics, and statistical reasoning.
- **Computational thinking:** decomposition, abstraction, pattern recognition, and algorithmic reasoning.

## Suggested resources

Add curated textbooks, university lecture series, interactive visualizations, exercises, and original notes in subject-specific sections. Include prerequisites and level so learners can choose an appropriate starting point.

## Contribute

Use Markdown for explanations and exercises. Keep worked examples close to the concept they illustrate and cite sources.
