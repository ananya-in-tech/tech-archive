# Software Development

Practical resources for designing, building, testing, deploying, and maintaining software applications.

## Development domains

- **Web development:** HTML, CSS, browser fundamentals, frontend, backend, and full-stack development.
- **Application development:** Android, iOS, Flutter, React Native, and cross-platform development.
- **Desktop development:** native and cross-platform desktop applications.
- **Game development:** game programming, engines, graphics, and interactive systems.
- **API development:** REST, GraphQL, API design, authentication, and integration.

## Recommended organization

Keep framework-specific tutorials with the relevant platform or development domain. Include the technology/version where it affects accuracy, and prefer official documentation for reference material.

For architecture, design patterns, testing strategy, deployment practices, and distributed systems, see [Engineering Practices](../06-engineering-practices/README.md).
