# Projects and Practice

Turn knowledge into practical engineering experience through guided projects, exercises, case studies, and implementation challenges.

## Collections

- Project ideas by domain and difficulty
- Guided and milestone-based projects
- Hands-on coding exercises
- Engineering case studies
- Open-source contribution opportunities
- Capstone and portfolio project references

Each project entry should describe the problem, expected outcomes, suggested skills, prerequisites, possible extensions, and useful references. Link to external repositories when the source project is maintained elsewhere; do not copy large projects into this archive without a clear reason and compatible license.
