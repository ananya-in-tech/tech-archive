# System Design

Resources for reasoning about the architecture, behavior, scale, and operational characteristics of software systems.

## Topics

- Requirements gathering and capacity estimation
- Low-level design and object modeling
- High-level architecture
- APIs, data modeling, and storage choices
- Caching, queues, and asynchronous processing
- Load balancing, partitioning, and replication
- Distributed systems and consistency
- Reliability, observability, and failure handling
- Security, privacy, and cost trade-offs

## Learning resources

Organize system design notes, architecture diagrams, case studies, reference architectures, and interview exercises here. Explain trade-offs and assumptions rather than presenting one design as universally correct.

For interview-specific prompts and mock exercises, also see [System Design Interviews](../../interview-preparation/README.md).
