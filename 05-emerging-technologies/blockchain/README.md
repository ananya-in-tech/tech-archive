# Blockchain

Resources for understanding distributed ledgers, cryptographic primitives, consensus, smart contracts, and decentralized applications.

## Topics

- Distributed-ledger fundamentals
- Hashing, signatures, and cryptographic building blocks
- Consensus mechanisms
- Smart-contract development and security
- Decentralized applications
- Token standards and blockchain interoperability
- Layer 2 systems and scaling

Prefer protocol specifications, official developer documentation, security audits, and reputable research. Note network, language, and framework versions.
