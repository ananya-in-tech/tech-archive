# Data Science

A curated collection for learning how to collect, clean, analyze, visualize, and communicate insights from data.

## Topics

- Python and data-analysis workflows
- Data cleaning and exploratory analysis
- Probability and statistical inference
- Data visualization and storytelling
- SQL and analytical databases
- Experimentation and A/B testing
- Data engineering and big-data foundations

Clearly document dataset sources, licenses, schemas, and any privacy considerations. Never commit personal or confidential data.
