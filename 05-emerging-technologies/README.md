Explore evolving technology domains through curated courses, technical notes, documentation, research, tools, and hands-on learning resources.

## Curation principles

Prioritize technically credible sources, foundational explanations, official documentation, and reputable research. For fast-moving topics, include publication dates, software versions, and a last-checked date where useful. Clearly distinguish introductory material, implementation guides, and research-level content.
