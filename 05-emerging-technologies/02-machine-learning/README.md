# Machine Learning

Resources covering the theory, implementation, evaluation, and responsible use of machine-learning systems.

## Topics

- Supervised and unsupervised learning
- Regression and classification
- Feature engineering and model evaluation
- Deep learning and neural networks
- Computer vision and natural language processing
- Reinforcement learning
- Model deployment and MLOps
- Responsible machine learning

Include datasets and notebooks only when their licensing and size are appropriate for the repository. Record dataset provenance and relevant model/library versions.
